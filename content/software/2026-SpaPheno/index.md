`SpaPheno` is an open-source interpretable machine learning R package explicitly designed to bridge spatial transcriptomic profiles and clinical phenotypes, advancing spatially informed precision oncology research. Built upon the core framework proposed in the benchmark study, this package enables systematic integration of high-resolution spatial transcriptomics data with clinically annotated bulk RNA-seq data, empowering researchers to mine spatially resolved biomarkers that are predictive of critical patient outcomes including survival, tumor staging, and immunotherapy response.
